# Sub-Antarctic (가제) — 심해 탐험 액션 프로토타입 설계

날짜: 2026-07-03
상태: 승인됨 (프로토타입 범위)

## 1. 목적

브라우저에서 바로 플레이 가능한 프로토타입으로 다음을 검증한다:

1. **유영 이동 + 헤드램프 탐험 + 작살 전투**의 손맛이 재밌는가
2. **채집 → 생환 → 업그레이드** 루프의 긴장감("더 내려갈까, 돌아갈까")이 작동하는가
3. 승인된 비주얼 무드(`samples/sample_exploration.png`, `samples/sample_combat.png`)가 실시간으로 재현되는가

장기 방향은 아울보이형 탐험 액션 + 채집/성장 루프. 이 프로토타입은 그 첫 수직 조각이다.

## 2. 기술 스택

- **HTML5 Canvas 2D + 순수 JS (ES 모듈)**. 빌드 도구 없음 — 정적 서버(`npx serve` 또는 `python -m http.server`)로 실행. `file://`은 ES 모듈 제약으로 미지원.
- 내부 해상도 **480×270**, 정수배 최근접(nearest-neighbor) 업스케일. `image-rendering: pixelated`.
- 데스크톱 + 모바일 브라우저(iOS Safari, Android Chrome) 동시 지원.
- 그래픽은 전부 프로시저럴(샘플 렌더러와 같은 기법). 애셋팩 교체는 재미 검증 후 별도 프로젝트.

### 라이팅 파이프라인 (샘플의 실시간 버전)

1. 씬을 오프스크린 캔버스에 렌더 (배경 그라데이션 → 패럴랙스 실루엣 → 타일 → 스프라이트)
2. 라이트맵 캔버스: 깊이 기반 앰비언트(위 밝고 아래 어두움) 위에 광원을 `lighter`로 누적
   - 헤드램프 원뿔(조준 방향), 발광 산호/켈프 팁, 해파리, 보스 루어, 임팩트 플래시
3. 씬 × 라이트맵을 `multiply` 합성, 발광체(emissive)는 위에 `lighter`로 추가
4. 파티클(부유물·기포)은 지역 밝기에 따라 알파 조절
5. 성능 원칙: 480×270 고정이므로 저사양 모바일에서도 60fps 목표, 광원 수 상한(~12개) 유지

## 3. 조작 (트윈스틱, 양 플랫폼 동일 게임성)

| 동작 | 데스크톱 | 모바일 (터치) |
|---|---|---|
| 유영 | WASD / 방향키 | 왼쪽 가상 스틱 |
| 조준 (헤드램프+작살 방향 일치) | 마우스 | 오른쪽 가상 스틱 |
| 발사 | 마우스 클릭/홀드 | 오른쪽 스틱을 기울이고 있는 동안 자동 발사 |
| 부스트 대시 | Shift | 부스트 버튼 (왼쪽 스틱 옆) |

- 유영은 관성 기반: 가속/감속이 부드럽고 물속 저항감이 있는 이동 (아울보이 비행 감각)
- 부스트는 짧은 무적 없는 회피 이동, O2 소량 소모
- 헤드램프 = 시야 = 조준선이 하나로 묶임 (심해 테마의 핵심 감각)
- 터치 UI는 손가락 기준 넉넉한 히트박스, 스틱은 터치 시작점 기준 플로팅

## 4. 게임 구조

### 맵
- 손으로 짠 단일 맵, 약 5×4 화면 (내부 해상도 기준 2400×1080 world px)
- **ASCII 타일맵**(16px 타일)으로 제작 — 코드에서 문자열 배열로 정의, 편집 용이
- 수직 구성: 상단 = 거점/밝음 → 하단 = 보스/암흑. 깊이에 따라 앰비언트 광 감소
- 타일 종류: 물(빈 공간), 바위(충돌), 기포 분출구(O2 회복), 광물 노드, 곰치 구멍, 체크포인트

### 거점 (잠수정)
- 맵 최상단. 접촉 시: 소지 광물이 은행됨(안전), O2/체력 완전 회복, 업그레이드 메뉴 열림

### 자원 & 성장 (프로토타입은 얇은 조각만)
- **광물**: 크리스탈 1종 (깊을수록 밀집·고가치 배치). 파괴 가능한 노드에서 드랍, 접촉 획득
- **생환 규칙**: 소지 광물은 죽으면 전부 소실. 거점 복귀 시 은행되어 확정
- **업그레이드 (프로토타입: 2종만)**: ① O2 탱크 용량 +50% (크리스탈 8개) ② 작살 데미지 +50% (크리스탈 12개). 각 1단계, 은행된 크리스탈로 구매. 맵 전체 크리스탈 총량 ~35개 (튜닝 가능 상수로 관리)
- 본편 확장 예약(구현하지 않음): 광물 다종화, 램프/방어/적재량/부스트 업그레이드, 유물 수집. 인벤토리·화폐 필드는 확장 가능한 구조로 설계

### 생존 시스템
- **O2**: 시간에 따라 감소(기본 ~90초 분량), 기포 분출구·거점에서 회복. 0이 되면 체력이 초당 1씩 감소
- **체력**: 하트 3개. 피격 시 1 감소 + 1.5초 무적(점멸) + 넉백
- **사망**: 소지 광물 소실, 마지막 체크포인트에서 부활 (체크포인트는 맵에 2개 + 거점)

### 적 (3종 + 보스)
| 적 | 행동 | 역할 |
|---|---|---|
| 해파리 | 느리게 부유, 경로 왕복. 접촉 시 피해 + 0.8초 이동둔화 | 지형형 장애물 |
| 곰치 | 바위 구멍에 은신 → 플레이어 근접 시 튀어나와 물기 → 복귀 | 매복 긴장감, 램프로 미리 발견 가능 |
| 심해어 떼 | 평소 배회, 플레이어 **불빛 원뿔에 닿으면** 어그로 → 추격·돌진 | 빛=시야 vs 빛=위험 트레이드오프 |

### 보스: ABYSSAL ANGLER
- 맵 최심부 보스 아레나 (진입 시 입구 봉쇄 + 보스 체력바)
- **페이즈 1 (100~50%)**: 돌진 공격(루어가 깜빡인 뒤 직선 돌진), 심해어 쫄몹 소환(2~3마리)
- **페이즈 2 (50% 이하)**: **조명 페이즈** — 앰비언트 완전 암전, 보스 루어와 플레이어 램프만 광원. 같은 패턴이 더 빠르게
- 처치 → 침몰선 유물 획득 → 거점 귀환 → 클리어 화면 (플레이 10~15분 분량)

## 5. 범위 제외 (YAGNI)

메트로배니아 능력 게이팅, 저장 시스템(세션 내 진행만), 광물 다종화·전체 상점, 애셋팩 통합, 본격 사운드(WebAudio 비프 수준의 효과음만), 게임패드, PWA 패키징.

## 6. 코드 구조

```
index.html
src/
  main.js        # 게임 루프(고정 타임스텝), 씬 전환(타이틀/플레이/클리어)
  input.js       # 키보드+마우스 / 터치 트윈스틱 통합 → 추상 입력 상태
  world.js       # ASCII 타일맵 파싱, 타일 충돌(AABB), 광물 노드·분출구 배치
  player.js      # 유영 물리, O2/체력, 작살 발사, 부스트, 인벤토리
  enemies.js     # 적 3종 상태기계
  boss.js        # 보스 상태기계 + 아레나 연출
  lighting.js    # 라이트맵 합성 (앰비언트/원뿔/점광원)
  particles.js   # 기포·부유물·스파크 풀
  render.js      # 배경/패럴랙스/스프라이트 렌더, 카메라
  sprites.js     # 프로시저럴 스프라이트 생성 (로드 시 1회 캔버스에 베이크)
  hud.js         # O2바/하트/크리스탈 카운트/보스바/업그레이드 메뉴
  audio.js       # WebAudio 최소 효과음
```

- 각 모듈은 명확한 단일 책임, `update(dt)` / `draw(ctx)` 인터페이스 통일
- 게임 상태(플레이어·적·인벤토리)는 렌더와 분리 — 로직은 캔버스 없이 실행 가능

## 7. 검증

- **단위 테스트 (Node, 캔버스 불필요)**: 타일 충돌 해석, O2 감소/회복 계산, 은행/소실 규칙, 적 상태 전이, 보스 페이즈 전환
- **플레이 체크리스트 (수동)**: 유영 손맛(관성·부스트), 램프 조준감, 작살 타격감, 심해어 어그로 트레이드오프 체감, O2 압박으로 인한 귀환 판단 발생 여부, 모바일 실기 터치 확인, 60fps 유지
- 성공 기준: 처음 플레이하는 사람이 설명 없이 조작을 이해하고, "한 번 더 내려가볼까"라는 말이 나오면 통과

## 8. 오류 처리

- 게임 루프는 `requestAnimationFrame` + 고정 타임스텝(탭 비활성 후 복귀 시 dt 클램프로 터널링 방지)
- 터치·마우스 이벤트 동시 발생(하이브리드 기기) 시 마지막 입력 소스 우선
- 모바일 세로 모드: 가로 회전 안내 오버레이 표시
