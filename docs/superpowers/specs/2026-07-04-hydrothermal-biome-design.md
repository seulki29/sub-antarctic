# Sub-Antarctic 2단계-1: 열수분출구 지대 — 설계

날짜: 2026-07-04
상태: 승인됨
기반: 저장 시스템 (master aa35661, 테스트 43개)

## 1. 목적

첫 번째 신규 바이옴. **단일 맵을 아래로 확장**해 열수분출구 지대를 추가하고, **구매형 게이팅(내압 강화복)** 과 **중간보스**로 중반 이후의 목표를 만든다.

## 2. 맵 확장 (150×68 → 150×100)

- 기존 68행 아래로 32행 추가 (행 68–99). 기존 맵 데이터·좌표 불변 (세이브 호환)
- 새 지역 지형: 좁은 수직 갱도 + 넓은 열수 챔버 2–3개, 바닥 곳곳에 증기 분출구
- **진입로는 정확히 1곳**: 기존 심층(행 55 부근)에서 내려가는 수직 통로(열 20–24 부근, 폭 3), 통로에 **압력 장벽 `P` 가로 라인**(폭 전체)
- 신규 타일:
  - `P` (압력 장벽): `world.hullOpen`이 false면 solid. parseMap이 `world.pressure = [{tx,ty}]` 수집. 렌더: 붉은 경고 셰브론 + 은은한 적색 발광
  - `H` (증기 분출구): 물 타일로 취급, `world.hydroVents = [{x,y}]` 수집. 바닥 타일 바로 위에 배치
- 배치(신규 지역): 광물 노드 `C`×6 (전부 마그마 존), 공기 분출구 `V`×2, 해파리 `J`×2, 곰치 `M`×2, 증기 `H`×6–8, 중간보스 `B2`? → 새 마커 `Z` (중간보스 스폰) 1개 — 최심부 챔버

## 3. 마그마 결정 (4번째 광물)

- `MINERALS.magma = { value: 8, color: '#ffb040' }`
- `mineralForRow`: `tileY >= 68 → 'magma'` (기존 경계 유지: <18 crystal / <40 pearl / <68 abyss ← **abyss 상한 40→68로 자연 확장, 68 미만은 기존과 동일 결과**)
- 스프라이트: GEM_TONES.magma `{ dark:'#b84a10', main:'#ff9a30', hi:'#ffe0a0' }`
- **난이도 트리밍 제외**: `applyDifficulty`는 kind==='magma' 노드와 행≥68의 분출구를 트리밍 대상에서 제외 (신규 지역은 고정 콘텐츠). 기존 카운트(16/12/9 등)는 구지역 기준 그대로

## 4. 게이팅: PRESSURE HULL (구매형)

- `UPGRADES.hull = { cost: 24, label: 'PRESSURE HULL' }` (6번째 업그레이드)
- 게임: `world.hullOpen = player.upgrades.hull` — 생성 시(세이브 복원 포함)와 구매 직후 갱신
- 장벽 앞 접근 시(미보유) HUD에 경고 텍스트 1줄 노출: `NEED PRESSURE HULL` (장벽 타일 약 3타일 반경 이내)
- 메뉴 레이아웃 조정: 버튼 6+CLOSE — bh 22·gap 4·시작 y 56 (전부 패널 y28–246 내)

## 5. 해저드: 증기 분출

각 분출구는 독립 주기(좌표 해시로 위상 오프셋):
- idle 2.5s → **telegraph 0.8s** (기포·잔글로우) → **erupt 1.2s** (분출)
- erupt 중 분출구 위 3타일(48px) 세로 기둥이 피해 판정: 접촉 시 `player.damage(1)` (무적 존중) — 적에게는 무해
- 렌더: erupt 시 주황-백색 증기 기둥 + 강한 점광원, telegraph 시 기포 파티클
- 로직은 순수 함수 `steamPhase(time, seed) → 'idle'|'telegraph'|'erupt'` 로 분리 (테스트 대상)

## 6. 바이옴 연출

- 배경 그라데이션: 행 68 이하에서 적갈색 톤으로 블렌드 (RAMP에 심부 스톱 추가)
- 앰비언트 라이트: 행 68 이하 약간 상승 + 붉은 틴트 (열수 발광 — ambColor에 깊이별 웜 시프트)
- 데코: 행 68 이하 산호 대신 **관벌레(tube worm)** 팔레트 (적/백), genDecor에서 행 기준 분기

## 7. 중간보스: VENT CRAWLER (열수 게)

- `Z` 마커 위치에 스폰. **게이트 없음** — 챔버에 서식, 접근하면(200px) 보스바 표시 + BGM boss 모드
- 스탯: HP 20, 몸체 ~70×40, 접촉 피해 1
- 행동 (바닥 보행형 — Angler와 차별화):
  - **patrol**: 챔버 바닥을 좌우로 기어다님 (속도 40)
  - **lunge**: 플레이어가 수평 ±120px·상방 80px 내면 텔레그래프 0.5s 후 수평 돌진 (속도 200, 벽/거리 한계에서 정지)
  - **steam**: 4–6초마다 자기 위치에 증기 기둥 1.2s (해저드와 동일 판정)
- 처치: 마그마 결정 픽업 12개 산란 (가치 96) + `hydroBossDead` 저장 플래그. 리스폰 없음
- 플레이어 사망 시: 크롤러는 위치/HP 리셋 (Angler 리셋과 동일 원칙, 스폰 앵커 고정)
- 구현: `src/crawler.js` 별도 클래스 (Angler 수정 없음)

## 8. 저장 호환

- 스키마 v1 유지, 선택 필드 추가: `hydroBossDead: bool` (구 세이브에 없으면 false — isValidSave 통과)
- 노드 좌표 키 방식 그대로 (신규 노드 자동 포함). 기존 세이브 로드 시 신규 지역은 미탐험 상태로 자연 추가

## 9. 범위 제외

두 번째 유물/엔딩 변경, 신규 적 종족(기존 J/M 재배치만), 침몰선/빙하 바이옴, 절단기·소나, 보스 러시.

## 10. 검증

- 단위: mineralForRow(67→abyss, 68→magma), steamPhase 주기 경계, applyDifficulty 마그마/신규 vent 제외, 맵 테스트 (150×100, 신규 카운트, **hull 미보유 시 신규 지역 도달 불가 + hullOpen 시 도달 가능 + Z 마커 존재**), crawler 상태 전이, 세이브 hydroBossDead 라운드트립
- 플레이: 장벽 경고→HULL 구매→진입, 증기 리듬 회피, 크롤러 전투(바닥전+증기), 마그마 경제 체감, 기존 세이브 이어서 신규 지역 진입, 60fps (확장 맵 + 증기 파티클)
